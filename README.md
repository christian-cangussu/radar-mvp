# RADAR

Contratación pública, sin ruido.

Frontend de producto para RADAR: plataforma que detecta, clasifica y prioriza oportunidades de contratación pública según el perfil real de cada empresa.

## Stack
- Next.js 16
- React 19
- TypeScript
- Supabase (backend en integración)
- Vercel / Coolify compatible

## Rutas
- `/` — landing comercial
- `/dashboard` — demo del producto

## Desarrollo
```bash
npm install
npm run dev
```

## Diseño
La dirección visual se inspira en patrones de producto B2B de alta gama: producto visible desde el hero, tipografía editorial, contraste institucional, jerarquía fuerte y mínima dependencia de clichés visuales de IA.
